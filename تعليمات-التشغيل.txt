تعليمات تشغيل موقع — كشتات عايلة الكري
=====================================================

تم تعديل الموقع من نسخة "كشتات عائلة حسين العويشي" إلى "كشتات عايلة الكري".
تم تغيير العنوان في جميع الصفحات، واستبدال بيانات الاعتماد (Firebase / Cloudinary / المشرف)
بمكانات فارغة يجب عليك تعبئتها — حتى لا يختلط بياناتك بعائلة أخرى.

الملفات الموجودة (ارفعها كلها بنفس الأسماء):
  index.html            (تحويل تلقائي لصفحة الدخول)
  login.html            (صفحة الدخول)
  home.html             (الرئيسية)
  city.html             (إضافة مدينة)
  place-detail.html     (تفاصيل المكان)
  add-place.html        (إضافة/تعديل مكان)
  add-purchase.html     (إضافة مشتريات)
  purchases.html        (قائمة المشتريات)
  profile.html          (حسابي)
  admin-dashboard.html  (لوحة المشرف)
  firebase-config.js    (إعداد Firebase — عدّله!)
  auth.js               (بيانات المشرف وCloudinary — عدّله!)
  db.js                 (قاعدة البيانات — لا يحتاج تعديل)

=====================================================
الخطوة 1: إنشاء مشروع Firebase (مجاني)
=====================================================
1. افتح https://console.firebase.google.com وسجّل الدخول بحساب جوجل.
2. اضغط "Add project" وسمّه مثلاً "alkri-places" → تابع (لا تحتاج Analytics).
3. داخل المشروع من القائمة الجانبية:
   • Firestore Database → Create database → اختر "Start in test mode" → أي موقع → Enable.
   • Storage → Get started → Next → Done.
4. من القائمة الجانبية اضغط أيقونة الترس ⚙️ (Project settings) → أسفل الصفحة في "Your apps"
   اضغط أيقونة الويب </> → سجّل اسم التطبيق → ستحصل على بيانات بهذا الشكل:
       apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
5. افتح ملف firebase-config.js وضع بياناتك مكان الكلمات YOUR_API_KEY إلخ.

=====================================================
الخطوة 2: إنشاء حساب Cloudinary (مجاني لرفع الصور)
=====================================================
1. افتح https://cloudinary.com وأنشئ حساباً مجانياً.
2. من Dashboard انسخ "Cloud name" (مثل dk1abc2xy).
3. من القائمة: Settings → Upload → "Add upload preset" → اسمه مثلاً alkri_places
   وفي "Signing Mode" اختر "Unsigned" → احفظ.
4. افتح ملف auth.js وفي الأعلى غيّر:
       const CLOUDINARY_CLOUD = 'اسم_سحابتك';
       const CLOUDINARY_PRESET = 'اسم_preset_الذي_أنشأته';

=====================================================
الخطوة 3: تغيير بيانات المشرف
=====================================================
في ملف auth.js الأعلى غيّر:
   const ADMIN_PHONE = "رقم جوالك";       (مثال 05XXXXXXXX)
   const ADMIN_PASSWORD = "كلمة سر قوية"; (غيّر admin123!)
   const ADMIN_EMAIL = "بريدك الإلكتروني";

وفي صفحات login.html و profile.html يظهر بريد ورقم المشرف لقسم "تواصل مع المشرف" —
غيّرهما من نفس الملفين (ابحث عن admin@example.com و 0500000000).

=====================================================
الخطوة 4: الرفع على GitHub Pages (مجاني)
=====================================================
1. أنشئ حساباً على github.com ثم مستودع جديد (Repository) مثلاً باسم alkri-places.
2. ارفع جميع الملفات (بنفس الأسماء، بدون مجلدات) إلى المستودع.
3. من المستودع: Settings → Pages → Source اختر "main" branch و /(root) → Save.
4. بعد دقيقتين سيعمل الموقع على: https://اسمك.github.io/alkri-places/
   (أو أي استضافة أخرى تقبل ملفات ثابتة مثل Netlify / Vercel).

=====================================================
الخطوة 5: أول تشغيل
=====================================================
1. افتح الموقع → من صفحة الدخول اختر تبويب "المشرف" → أدخل كلمة مرور المشرف.
2. من لوحة المشرف: أضف أفراد العائلة (بالرقم أو البريد) حتى يتمكنوا من الدخول.
3. من الرئيسية اضغط زر "مدينة" لإضافة المدن (الخبر، الرياض، الدمام... إلخ).
4. بعدها يمكن لأي عضو إضافة أماكن وصور.

ملاحظات تقنية مهمة:
• قواعد Firestore: اتركها في وضع test mode مؤقتاً، أو ضع قاعدة تسمح بالقراءة والكتابة
  للجميع (الموقع يستخدم دخولاً مخصصاً وليس Firebase Auth).
• إذا ظهر خطأ "index" عند عرض أماكني، اتبع الرابط الذي يظهره المتصفح لإنشاء الفهرس.
• رقم الدخول الذي أعطيتني إياه (0544366933) مسجل لدى العائلة الأصلية فقط —
  في موقعك الجديد ستضيف الأرقام بنفسك من لوحة المشرف.
